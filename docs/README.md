# ZMK Documentation

This website is built with [Astro](https://astro.build) and
[Starlight](https://starlight.astro.build).

## Installation

```sh
pnpm install
```

## Local Development

```sh
pnpm dev
```

## Build

```sh
pnpm build
```

The build output is written to `dist/`.
